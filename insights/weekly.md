## 잘 되는 패턴 (매일 문제에 반영)
1. **숫자·수식 퍼즐 + 영어 한 줄** — curionics(팔로워 5.4천)의 릴스 3개가 각각 216만~299만 조회(그 계정 평소의 70~96배).
   공통점: 화면 가운데 큰 수식 하나(예: X²=49·X+Y=5, 19−18=18에 선 하나), 한국어 후킹 + 괄호 안 영어 문장.
   → 수열·성냥개비·창의력·도형 문제는 `question_en` 에 영어 한 줄을 넣는다. (예: Move one matchstick to make the equation true.)
2. **일상 숫자에 함정 하나** — eundokki12: "오후 1시에 가장 가까운 시간은?" 127만, "숫자 4개를 더해 100 만들기" 92만, "300 만들기" 53만, "00:00에 가장 가까운 시간은?" 16만.
   → 시계·시간·날짜·돈처럼 누구나 아는 숫자에 함정을 하나 넣는다. 정답은 코드로 검증.
3. **터진 형식은 숫자만 바꿔 다시** — eundokki12는 '가장 가까운 시간', '숫자 더하기'를 여러 번 변형해 올렸다.
   → 우리 계정 1등(성냥개비, 평균 시청 9.4초·유일한 공유)처럼 반응 좋은 형식은 2~3주 뒤 변형해서 다시 쓴다.
4. **초성 퀴즈** — 365brain_exercise 최고 조회가 초성 퀴즈(6만, 평소 8.6배). 주제는 속담·사자성어·일반명사(저작권 문제 없는 것).
5. **댓글이 폭발하는 형식** — 도형 세기(quiz_many 삼각형 세기: 좋아요 5천·댓글 3,986), 날짜 문해력(mseoh_0829 '사흘 뒤 요일': 좋아요 2.1만·댓글 3,732). 답이 숫자 하나라 댓글 달기 쉽다.
6. **공유가 많은 형식** — 여러 문제 묶음(sangsik_k "다 맞으면 상위권": 좋아요 8,466·공유 9,663), 암호 해독(mandoobrain 동물=13…: 공유 1,909 ≈ 좋아요), 선 하나 긋기(curionics: 공유 1,740).
7. **화면에 행동 유도 문구** — "정답과 풀이방법을 댓글창에 적어주세요", "정답은 댓글에!", "팔로우&좋아요". 풀이까지 적게 하면 댓글이 길어진다.
8. **후킹 문구 실제 사례** — hooks.yaml 에 추가 (바로 풀면 천재 / 미국 대학 시험 문제 / 암산으로 풀 수 있나요? / 요즘 20대 97%가 틀린 문제 / 다 맞으면 상위권 등).

## 하지 않을 것
- 다른 계정의 문제를 그대로 옮기지 않는다. ('3등 추월', '사흘 뒤 요일'처럼 이미 많이 돈 소재는 우리 표현·다른 소재로 바꾼다.)
